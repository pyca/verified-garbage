Retained-state probe (NOT integrated or fully verified)
------------------------------------------------------
BlockMixFused.lean retains words 0..11 in GPRs and 12..15 in scratch across
Salsa invocations. Scratch[16,48) holds loop metadata; [48,56) is a temporary;
[64,112) holds saved caller registers. It avoids saving/restoring loop GPRs
and reloading the previous X for every Salsa invocation.

The Retained proof module proves the complete fused inner core's arithmetic,
output words, memory frame, state retention, and trace equivalence. FusedLoop
contains metadata preservation and byte-specification helper proofs.
The full BlockMix loop/ABI proof and its production integration are NOT
complete. There is no Verified artifact for blockMixFused. The public API
continues to use the already verified inlined scalar BlockMix.
