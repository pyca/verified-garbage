# Security

Verified Garbage is experimental: see the README for what its proofs show, what
they assume, and what is not verified.

Report a vulnerability privately, through
[GitHub](https://github.com/pyca/verified-garbage/security/advisories/new),
not in a public issue. Say what is affected, which crate version, CPU and
target, and how to reproduce it. A proof whose statement, specification or
hardware model is wrong, so that the code proven correct is not secure, is a
vulnerability too.

Only the latest release gets fixes. Fixes are announced as advisories on GitHub
and in the [RustSec database](https://rustsec.org).
