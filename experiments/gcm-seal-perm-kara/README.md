Run-only polynomial-multiply experiment, based on 8c603b334.

Variants 0/4 use the registered fused seal; 1/5 use two vperm instructions
for each pair, with four mask loads per eight-block batch; 2/6 use the same
packing and mask loads, but compute the two-block GHASH product with three
polynomial multiplies and Karatsuba cross terms instead of four multiplies.
3/7 are OpenSSL with a reused key context. The copy variants include memcpy.

All assembly is generated by GcmSealPermKaraProbe.lean using the Lean ISA
model and printer. From lean/, reproduce it with:

    lake env lean --run ../experiments/gcm-seal-perm-kara/GcmSealPermKaraProbe.lean ../experiments/gcm-seal-perm-kara/gcm-seal-perm-kara.s

The fixtures are the 54 complete-seal Spec cases from run 41281629409,
repeated for three implementations. All passed POWER8 emulation locally.
The workflow checks them natively before timing and checks all benchmark
inputs against OpenSSL. It uses 25 interleaved samples and eight process
copies, reporting each copy's median and the median of those medians.
