Run-only AES final-key scheduling experiment, based on 8c603b334.

Variants 0/5 use the registered fused seal; 1/6 use the previously measured
two-vperm GHASH packing. 2/7 preload the final AES round key into v9 after
the second cached round key has been consumed. The remaining rounds use v8,
so v9 survives until the last round. 3/8 combine this scheduling with vperm
packing. 4/9 are OpenSSL with a reused EVP key context. Copy variants include
memcpy. All variants use the twenty modeled volatile vector registers.

All assembly is generated by GcmSealPrefetchProbe.lean using the Lean ISA
model and printer. From lean/, reproduce it with:

    lake env lean --run ../experiments/gcm-seal-prefetch/GcmSealPrefetchProbe.lean ../experiments/gcm-seal-prefetch/gcm-seal-prefetch.s

The fixtures are the 54 complete-seal Spec cases from run 41281629409,
repeated for all four implementations. All passed POWER8 emulation locally.
The workflow checks them natively before timing and checks every benchmark
input against OpenSSL. Measurements use 25 interleaved samples and eight
process copies, reporting each copy's median and the median of those medians.
