Run-only register-allocation experiment, based on 8c603b334.

Variants 0/4 use the registered fused seal; 1/5 use two vperm instructions
for each pair, with four mask loads per eight-block batch; 2/6 accumulate
GHASH's middle and high terms in the already consumed ciphertext registers
v0/v1, freeing v11/v12 for the masks and removing two mask restores per
batch. All use only the twenty modeled volatile vector registers. 3/7 are
OpenSSL, with a reused EVP key context, in place/out of place respectively.
The copy variants include memcpy before seal.

All assembly is generated by GcmSealPermAccProbe.lean using the repository's
Lean instruction model and printer. From lean/, reproduce it with:

    lake env lean --run ../experiments/gcm-seal-perm-acc/GcmSealPermAccProbe.lean ../experiments/gcm-seal-perm-acc/gcm-seal-perm-acc.s

The frozen fixtures are the 54 complete-seal Spec cases from run
41281629409, repeated for three implementations. The driver checks them
before benchmarking and checks every benchmark input against OpenSSL.
Measurements use 25 interleaved samples and eight process copies; the job
reports each copy's median and the median of those medians.
