# Working: P-384's doubling on x86-64 with BMI2 and ADX (clean room)

## Entry 11: one reduction where dblJMul has two (before any code)

P-521's code is frozen (entry "Breach"). P-384: p = 2^384 - c with
c = 2^128 + 2^96 - 2^32 + 1; no spare bits, so no lazy sums: every stored
number is canonical. `dblJMul` has 8 products and 12 linear operations, each
with its own reduction. Three places reduce twice for one value needed:
  M  = t + t + t                 (2 operations)
  X3 = M^2 - S - S               (2)
  Y3 = M (S - X3) - (U + U)      (2, U = (2Y^2)^2)
Bounds: t < p so 3t < 3p; p - b needs no correction as b < p (b <= p - 1), so
a - 2b = a + 2 (p - b) mod p and 0 <= a + 2 (p - b) < 3p. Both sums V < 3p
are six words and a top word t in {0, 1, 2}, t = floor(V / 2^384). Reduce:
2^384 = c mod p, so V' = low + t c = V - t p.
  t = 2: V < 3p gives V' < p.   t = 1: V < 2 2^384 gives V' < 2^384 + c < 2p.
  t = 0: V' = V < 2^384 < 2p.
So V' < 2p always: one conditional subtraction (the tree's csub) ends it.
t c in words for t <= 2, k = (t << 32) - t: w0 = -k mod 2^64, w1 = k + t - (k != 0),
w2 = t: eight instructions, then one carry chain.
Count: 12 -> 9 linear operations, two kinds of new operation (3a; a - 2b).
Rejected: carrying 2Y (a run of doublings between additions is about 4 long in
verification, conversion at both ends); halving inside one doubling (a
further operation for the one it saves); Montgomery inputs up to 2^384
(a second carry would need a chain of its own).
Recognised: fusing small multiples is something I know libraries do and is
what my entry 1 barred as "any C a - D b"; the coordinator has since ruled
that what committed working derives from the formulas and the prime may be
used. The general C a - D b operation, p - b first with multiplications by
C and D, and w = 12 X Y^2 - 9 (..)^2 stay out.

## Entry 12: entry 11 measured and rejected; the order instead (before any code)

Prototype, chain of 200, real slots, TSC: the in-place doubling 506-519, with
entry 11's two operations 521. A fused triple is 16.5 against 19.6 for two
additions: nothing, since linear operations overlap the products (a dependent
product is 65). Rejected.

(dblJMul's 4M + 4S; and Z3 = (Y+Z)^2 - Y^2 - Z^2, 3M + 5S), with only the
